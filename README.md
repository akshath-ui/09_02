## 🌊 The Problem
Fishermen arriving at harbours often lack real-time information regarding:
- Which fish species are fetching the best prices locally versus at nearby harbours.
- Availability of crucial resources like ice plants and cold storage.
- Active buyers and immediate market demand.

## 💡 The Solution
The **Smart Fishing Harbour Information System** is a unified, real-time dashboard connecting fishermen, traders, harbour management, and auction operators.

### Core Roles & Features
*   🚤 **Fisherman Dashboard:** Live Price Board, Harbour Price Comparison, Resource Status, and Notices/Alerts.
*   🚚 **Fish Vendor/Trader Hub:** Track active orders, live auction lots, and market price trends.
*   🏛️ **Harbour Authority / Admin:** Real-time KPIs (boats at sea, landed catch) and emergency broadcast systems.
*   🔨 **Auction Owner Dashboard:** Manage active fish lots and live countdown bidding.
*   🏗️ **Maintenance Dashboard:** Track and assign infrastructure repairs.
*   🐟 **Customer View:** Locate nearby sellers based on fresh catch availability and budget.

## 🚀 Key Technical Highlights
- **Zero-Dependency Architecture:** Runs entirely on standard HTML5, CSS3, and Vanilla JavaScript within a single file (`harbouriq(1).html`), ensuring instantaneous loading.
- **Mobile-First Design:** Fully responsive layout tailored for mobile devices.
- **Role-Based Access:** A built-in role switcher demonstrates tailored UI views for six distinct harbour personas.
- **Integrated AI Assistant:** Features a simulated "Harbour AI" chatbot that answers queries about prices, weather, and facility status.
